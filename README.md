# 🌴 Traveling Destinasi Lokal Indonesia

Website traveling yang elegan untuk menampilkan berbagai destinasi wisata lokal Indonesia dengan desain modern, animasi smooth, dan fully responsive.

## ✨ Fitur Utama

### 🎨 Desain
- **Earth Tone Color Palette**: Warna natural yang mencerminkan keindahan alam Indonesia
- **Modern Layout**: Typography clean dan readable dengan kombinasi Poppins & Playfair Display
- **Fully Responsive**: Sempurna di semua device (mobile, tablet, desktop)
- **Glassmorphism Effect**: Navigation bar dengan efek blur saat di-scroll

### 🚀 Fitur Interaktif
- **Hero Section**: Parallax effect dan smooth scrolling
- **Sticky Navigation**: Navbar yang tetap di atas saat scroll dengan efek glassmorphism
- **Destination Gallery**: Card-based layout dengan hover effects yang menarik
- **Filter System**: Filter destinasi berdasarkan kategori (Pantai, Gunung, Budaya, Kuliner)
- **Testimonial Carousel**: Slider otomatis dengan kontrol manual
- **Smooth Animations**: Fade-in animations menggunakan Intersection Observer
- **Animated Counters**: Statistik dengan animasi counter
- **Back to Top Button**: Tombol untuk kembali ke atas dengan smooth scroll

### 🎭 Animasi
- Fade in animations saat scroll (Intersection Observer)
- Smooth parallax effect pada background images
- Hover animations pada buttons dan cards
- Loading animations yang smooth
- Animated counters untuk statistik
- Smooth scroll behavior untuk navigasi

## 🗺️ Destinasi yang Ditampilkan

Website ini menampilkan 8 destinasi populer Indonesia:

1. **Pantai Kuta, Bali** - Pantai dengan pasir putih dan sunset memukau
2. **Gunung Bromo, Jawa Timur** - Sunrise spektakuler dengan kawah menakjubkan
3. **Candi Borobudur, Jawa Tengah** - Warisan budaya dunia UNESCO
4. **Raja Ampat, Papua Barat** - Surga bawah laut dengan keanekaragaman hayati terbaik
5. **Gunung Rinjani, Lombok** - Gunung berapi dengan danau kawah yang indah
6. **Kuliner Yogyakarta** - Kekayaan kuliner tradisional Indonesia
7. **Ubud, Bali** - Pusat seni dan budaya dengan sawah terasering
8. **Pantai Pink, Lombok** - Pantai unik dengan pasir berwarna pink

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Semantic markup untuk struktur yang baik
- **CSS3**: 
  - Flexbox & Grid untuk layout
  - Custom Properties (CSS Variables)
  - Animations & Transitions
  - Media Queries untuk responsive design
- **Vanilla JavaScript**: 
  - Intersection Observer API
  - Event Listeners
  - DOM Manipulation
  - Smooth Scrolling
- **External Resources**:
  - Google Fonts (Poppins & Playfair Display)
  - Font Awesome (Icons)
  - Unsplash (Images)

## 🚀 Cara Menggunakan
