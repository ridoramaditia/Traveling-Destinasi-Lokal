# Traveling Destinasi Lokal Indonesia

Sebuah website traveling dengan tampilan elegan yang dirancang untuk menampilkan berbagai destinasi wisata lokal Indonesia. Website ini menggunakan desain modern, animasi halus, dan sepenuhnya responsif di berbagai perangkat.

## Fitur Utama

### Desain

* Palet warna bernuansa earth tone yang merepresentasikan keindahan alam Indonesia.
* Tata letak modern dengan tipografi bersih dan mudah dibaca (Poppins dan Playfair Display).
* Responsif pada seluruh perangkat, termasuk mobile, tablet, dan desktop.
* Efek glassmorphism pada navigation bar dengan tampilan blur saat pengguna melakukan scroll.

### Fitur Interaktif

* Hero section dengan efek parallax dan smooth scrolling.
* Sticky navigation dengan efek glassmorphism saat di-scroll.
* Galeri destinasi menggunakan card-based layout dengan efek hover interaktif.
* Sistem filter berdasarkan kategori destinasi (Pantai, Gunung, Budaya, Kuliner).
* Testimonial carousel yang berjalan otomatis dan dapat dikontrol secara manual.
* Animasi fade-in menggunakan Intersection Observer.
* Animated counters untuk menampilkan statistik secara dinamis.
* Tombol “Back to Top” dengan smooth scroll.

### Animasi

* Animasi fade-in saat halaman di-scroll.
* Efek parallax pada gambar background.
* Animasi hover pada tombol dan kartu destinasi.
* Animasi loading yang halus.
* Animasi counter untuk menampilkan angka secara bertahap.
* Perilaku scroll yang lembut di seluruh navigasi.

## Destinasi yang Ditampilkan

Website ini menampilkan delapan destinasi wisata populer di Indonesia:

1. Pantai Kuta, Bali – Pantai berpasir putih dengan pemandangan matahari terbenam.
2. Gunung Bromo, Jawa Timur – Pemandangan matahari terbit dengan lanskap kawah yang menakjubkan.
3. Candi Borobudur, Jawa Tengah – Situs warisan dunia UNESCO.
4. Raja Ampat, Papua Barat – Surga bawah laut dengan keanekaragaman hayati tinggi.
5. Gunung Rinjani, Lombok – Gunung berapi dengan danau kawah yang indah.
6. Kuliner Yogyakarta – Ragam kuliner tradisional khas Indonesia.
7. Ubud, Bali – Pusat seni dan budaya dengan pemandangan sawah terasering.
8. Pantai Pink, Lombok – Pantai unik dengan pasir berwarna merah muda.

## Teknologi yang Digunakan

* **HTML5**: Struktur halaman menggunakan semantic markup.
* **CSS3**:

  * Layout menggunakan Flexbox dan Grid
  * Custom properties (CSS Variables)
  * Animasi dan transisi
  * Media queries untuk desain responsif
* **JavaScript (Vanilla)**:

  * Intersection Observer API
  * Event Listener
  * Manipulasi DOM
  * Smooth scrolling
* **Sumber Eksternal**:

  * Google Fonts (Poppins dan Playfair Display)
  * Font Awesome (ikon)
  * Unsplash (gambar)

## Cara Menggunakan

1. Buka file `index.html` melalui browser modern.
2. Website dapat langsung digunakan tanpa instalasi tambahan.
3. Pastikan koneksi internet aktif karena beberapa asset menggunakan CDN.

## Responsive Breakpoints

* Desktop: lebih dari 768px
* Tablet: 481px – 768px
* Mobile: hingga 480px
